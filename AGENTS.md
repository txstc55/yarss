# Project instructions

- Use two spaces per indentation level in all code, including Python and examples.
- Use spaces, never literal tab characters.
- Preserve this formatting in future changes. Run
  `ruff format --config yarss/pyproject.toml yarss example/viewer`.
- Keep package source code, installation scripts, and package configuration in
  the inner `yarss/` directory. The outer directory holds the repository,
  examples, data, and project documentation.
